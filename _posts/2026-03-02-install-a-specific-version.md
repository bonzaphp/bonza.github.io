## 安装方式

### 快速开始

```bash
# 克隆项目
git clone https://github.com/agentscope-ai/CoPaw.git
cd CoPaw

# 安装依赖
pip install -r requirements.txt

# 运行
python main.py
```

### Docker 部署

```bash
# 拉取镜像
docker pull agentscope/copaw

# 运行容器
docker run -d --name copaw agentscope/copaw
```
