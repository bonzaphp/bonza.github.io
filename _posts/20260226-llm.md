在当今数字化投资时代，如何利用 AI 技术提升投资决策的准确性和效率？今天要介绍的这个开源项目 [daily_stock_analysis](https://github.com/ZhuLinsen/daily_stock_analysis) 为我们提供了一个完美的解决方案。

## 项目概览

这是一个基于大语言模型（LLM）的 A股、港股、美股智能分析系统，能够每日自动分析自选股并推送「决策仪表盘」到多种企业通讯平台。最吸引人的是，整个系统完全零成本，纯白嫖，并且可以定时运行，无需服务器维护。

## 核心功能特性

### 🤖 AI 决策仪表盘
系统的核心亮点是一句话核心结论 + 精确买卖点位 + 操作检查清单。通过 AI 模型分析，为每只股票提供：
- 明确的买入/观望/卖出建议
- 具体的价格点位（买入价、止损价、目标价）
- 详细的操作检查清单，每项条件以「满足/注意/不满足」标记

### 📊 多维度分析
系统从多个维度进行全面分析：
- **技术面**：盘中实时均线、多头排列等技术指标
- **筹码分布**：分析筹码集中度和分散情况
- **舆情情报**：实时获取相关新闻和市场情绪
- **实时行情**：获取最新价格和成交量数据

### 🌍 全球市场覆盖
支持多个市场的股票分析：
- A股市场
- 港股市场
- 美股市场
- 美股指数（SPX、DJI、IXIC 等）

### 📈 大盘复盘功能
每日提供市场概览和板块涨跌分析，支持三种模式：
- cn：仅分析A股
- us：仅分析美股
- both：同时分析两个市场

### 🖼️ 图片识别功能
这是一个非常创新的功能 - 上传自选股截图，系统通过 Vision LLM 自动提取股票代码，一键加入监控列表。支持 JPG、PNG、WebP、GIF 格式。

### 🤖 Agent 问股功能
支持多轮策略对话，内置 11 种交易策略：
- 均线金叉
- 缠论
- 波浪理论
- 多头趋势
- 等等...

通过自然语言提问，如「用缠论分析 600519」，Agent 会自动调用实时行情、K线、技术指标、新闻等工具进行深度分析。

### 📢 多渠道推送
支持多种通知渠道：
- 企业微信
- 飞书
- Telegram
- 钉钉
- 邮件
- Pushover

### ⚙️ 自动化运行
通过 GitHub Actions 定时执行，每个工作日 18:00（北京时间）自动运行，无需服务器维护。

## 技术栈与数据来源

### AI 模型支持
项目支持多种 AI 模型，提供灵活的选择：
- AIHubMix（推荐）：一个 Key 即可使用 Gemini、GPT、Claude、DeepSeek 等全球主流模型
- Gemini（免费）
- OpenAI 兼容接口（支持 DeepSeek、通义千问等）
- Claude
- Ollama（本地部署）

### 数据来源
- **行情数据**：AkShare、Tushare、Pytdx、Baostock、YFinance
- **新闻搜索**：Tavily、SerpAPI、Bocha、Brave

## 内置交易纪律

系统内置了严格的风险控制规则：

### 严禁追高
乖离率超阈值（默认 5%）自动提示风险，对于强势趋势股会自动放宽限制。

### 趋势交易
要求 MA5 > MA10 > MA20 的多头排列才考虑买入。

### 精确点位
提供具体的买入价、止损价、目标价，让操作更加精准。

### 新闻时效控制
可配置新闻最大时效（默认 3 天），避免使用过时信息影响判断。

## 快速开始

### GitHub Actions 部署（推荐）
最简单的部署方式，5 分钟完成：

1. **Fork 仓库**：点击右上角 Fork 按钮
2. **配置 Secrets**：在仓库设置中添加必要的 API Key
3. **启用 Actions**：激活工作流
4. **手动测试**：运行一次测试工作流

### 必要配置
- **AI 模型**：至少配置一个 AI 服务（推荐 AIHubMix）
- **股票列表**：设置自选股代码，如 `600519,hk00700,AAPL,TSLA`
- **通知渠道**：至少配置一个推送渠道
