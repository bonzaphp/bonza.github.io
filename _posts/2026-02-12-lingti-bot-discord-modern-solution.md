**项目名称**: Lingti Bot  
**开发者**: ruilisi  
**项目地址**: [https://github.com/ruilisi/lingti-bot](https://github.com/ruilisi/lingti-bot)

## 安装和部署

### 📦 本地开发环境

#### 环境要求
- **Node.js**: 16.0+ 
- **npm**: 8.0+
- **Discord Bot Token**: Discord 应用令牌

#### 安装步骤
```bash
# 克隆项目
git clone https://github.com/ruilisi/lingti-bot.git
cd lingti-bot

# 安装依赖
npm install

# 配置环境变量
cp .env.example .env
# 编辑 .env 文件，添加 Discord Bot Token

# 启动开发服务器
npm run dev
```

#### 配置说明
```bash
# .env 文件配置示例
DISCORD_TOKEN=your_discord_bot_token
PREFIX=!
CLIENT_ID=your_client_id
GUILD_ID=your_guild_id
```

### 🚀 生产部署

#### Docker 部署
```bash
# 构建镜像
docker build -t lingti-bot .

# 运行容器
docker run -d --name lingti-bot lingti-bot
```

#### 云平台部署
- **Heroku**: 支持 Heroku 平台部署
- **Railway**: 支持 Railway 平台部署
- **DigitalOcean**: 支持 Droplet 部署
- **AWS**: 支持 AWS ECS 部署
